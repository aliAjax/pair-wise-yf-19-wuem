# hxyfront-62007 植物标本馆入库

源提示词编号：9

开发一个植物标本馆压制标本入库前端项目，工作人员可以录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态和馆藏位置。页面需要有入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情页。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62007

## 已实现的业务规则

- **外业离线登记**：录入采集号、物种（暂拟名）、海拔、生境、采集人（另含采集地点/时间），压制状态固定记为「待压制」，数据保存在浏览器本地。
- **回馆合并进编目库**：逐条原子提交，无半截写入。同采集号馆内已鉴定时，物种名称与鉴定状态一律按馆内（冲突保护），海拔与生境按最后一次外业改动覆盖；未鉴定记录则接受外业暂拟名。
- **断点续传**：合并按登记先后逐条进行，中途断网立即停在当前条；已合并不重放，未合上的留在本地待处理区，可补录后重试。校验不过（缺字段）的草稿不进入入库队列、不占柜位。
- **入库队列与柜位候补**：待压制 → 已压制 → 核验入库；只有「已入库」标本才占柜位容量。柜位满时排队候补，腾出空位后按标本采集时间从早到晚自动补位。
- **页面**：指标卡、离线登记表单、合并管线（待处理区）、入库队列、鉴定状态筛选的编目库、馆藏柜位记录、采集地点信息卡、合并审计日志、单份标本详情弹窗（压制流转 / 馆内鉴定 / 腾出柜位）。

## 演示路径

1. 初始柜位全部占满，待处理区有 4 条外业草稿：1 条与馆内已鉴定记录冲突、2 条新增、1 条漏填物种。
2. 点「联网合并」：冲突条保留馆内定名但更新海拔/生境；新增条进编目库；缺物种条被留在待处理区。
3. 合并途中切「离线」可观察断点停留；补录缺字段草稿后重新联网继续。
4. 对新记录执行「完成压制 → 核验入库」：柜位满则进入候补；在柜位记录里「腾出」任一层位，候补按采集时间自动补位。
